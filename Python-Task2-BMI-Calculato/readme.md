# BMI Calculator

A Python-based BMI Calculator developed as part of the OIBSIP Python Programming Internship – Task 2.

The BMI Calculator takes the user's weight and height as input, calculates the Body Mass Index (BMI), and displays the corresponding BMI category.

# Project Description

This project demonstrates how Python can be used to create a simple health-related calculation application.

The BMI Calculator:

-Takes the user's weight in kilograms.
-Takes the user's height in meters.
-Calculates the Body Mass Index (BMI).
-Displays the calculated BMI value.
-Determines the corresponding BMI category.
-Handles invalid user input.
-Prevents zero or negative values.

The project is designed as a beginner-friendly Python application and demonstrates the use of user input, mathematical calculations, conditional statements, and error handling.

# BMI Formula

The BMI is calculated using the following formula:

BMI = Weight / (Height × Height)

Where:

Weight = Weight in kilograms  
Height = Height in meters  

Example:

Weight = 60 kg  
Height = 1.65 m  

BMI = 60 / (1.65 × 1.65)

BMI = 22.04

Category = Normal weight

# BMI Categories

Below 18.5 : Underweight 
18.5 – 24.9 : Normal weight 
25.0 – 29.9 : Overweight
